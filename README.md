# 🤖 My First n8n AI Agent

My first AI Agent built with n8n and OpenAI GPT-5-mini.

This is my first hands-on project learning AI automation and AI agents without prior coding experience.

## 🚀 What This Agent Does

- Receives messages through an n8n Chat Trigger
- Uses an AI Agent to process requests
- Uses OpenAI GPT-5-mini as the language model
- Maintains conversational memory
- Responds to user questions
